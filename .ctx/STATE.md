## TL;DR
App desktop open source (Tauri 2 + React + Rust) pra tradução de ROMs com IA, local-first, patch-first. Spec em `docs/SPEC.md`. Spec 0–8 completa + PlayStation: NOVE plataformas detectáveis, NOVE com ciclo completo (RTSF, GBA, NDS, NES, SNES, GameCube, PS1 — incl. BIN raw 2352 com EDC/ECC regenerado e dump multi-track via .cue —, PS2, PSP). Parser ISO 9660 compartilhado (2048 + raw 2352, confirmado no kernel Linux), discriminador BOOT/BOOT2 no SYSTEM.CNF, PARAM.SFO parseado (título/disc id reais na evidência). Antes: SEIS plataformas com ciclo completo extrair→traduzir→reinserir→patch: RTSF, GBA, NDS, NES, SNES e agora GAMECUBE (FST confirmado no Dolphin: fst_offset/size BE em 0x424/0x428, entries de 12 bytes; extração por arquivo com resource_path; in-place sem checksum de disco; IN_MEMORY_MAX subiu pra 2 GiB — ISO real de 1.46 GiB passa, pico ~2x em RAM). Wii/WBFS/Wii U detecção. 88 testes. Próximos: abrir o repo, P2s de qualidade.

## Glossário do projeto
- **provider**: implementação de `TranslationProvider` (async); Ollama local ou endpoint OpenAI-compatible; modelo NUNCA hardcoded
- **TM**: translation memory por projeto; chave = texto normalizado (trim+collapse, case preservado) + par de idiomas
- **glossário**: termos por projeto injetados no prompt SÓ quando aparecem no batch; `no_translate` = manter original
- **allow_remote_translation**: guarda de privacidade — endpoint fora de localhost exige opt-in explícito
- **scanner (Camada A)**: descoberta genérica em `scan.rs`; NÃO garante reinserção segura (Camada B, Sprint 5)
- **.rtsproj**: diretório do usuário (project.json + translations.sqlite + subdirs); NUNCA contém cópia da ROM
- **synth**: fixtures sintéticas — proibido byte de jogo real no repo
