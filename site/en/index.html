Translate retro games with AI, on your computer

RomTranslate Studio is a desktop app. You drop your game file onto its window. It works out which console the game is for, finds the dialogue, translates it with the AI you choose and writes everything to a copy. Your original file stays as it was.

How to test it

  1. Click “Structured extraction”

    It is the pink button near the top. What to look for: a green notice says 20 “strings” (pieces of text) were saved, and a line below counts 18 chunks thrown away because they did not look like text. In the table, each row has the original line and its translation side by side.

  2. Click “Translate pending”

    It is in step 2, further down. What to look for: the progress bar moves and, at the end, a summary says how many lines were translated and how many failed. The AI here is simulated, so the table does not change.

  3. Click “Reinsert into working copy”

    It is in step 3. What to look for: the notice “Translated game ready and verified” and the tally of what happened: 11 translations applied and 7 lines kept as in the original.

Want to poke around? Click any row in the table to open that line and edit its translation. The made-up game is in English and is being translated into Portuguese, and the simulated messages inside the demo are in Portuguese too.

How it works, in six steps

  1. You drop in the file

    The app recognises which console the game is for and shows the clues it used to decide.

  2. It finds the text

    It separates the text from the rest of the file. Anything that only looks like text is thrown away.

  3. Hi! AI Oi!

    The AI translates

    You pick the AI. It gets several lines at a time and is told how much room each one has.

  4. Oi!

    Every line is checked

    The app checks the size, the codes hidden in the text (for example, the spot where the player's name goes) and the letters the game can write. Lines that do not fit go back to the AI on their own. You can also fix any line by hand.

  5. Oi!copy

    The translation goes into a copy

    The app writes the translated lines to a working copy and checks the result. Your original file is never modified.

  6. patch

    You get a patch

    A small file that holds only what changed (in IPS or BPS format). You share the patch instead of the game.

What you need

Your own game file

The digital copy of the game, stored as a file on your computer. The app works with a file you already have. It does not download games, and this site does not offer any.

A computer

Running macOS, Windows or Linux. The app is installed on it and the work happens there.

Hi! AI Oi!

An AI to translate

You pick one of these three options:

  • AI on your own computer (Ollama) free

    Ollama is a free program that runs the AI on your machine. Nothing leaves it. A small model struggles to keep lines short.

  • Your ChatGPT subscription the plan you already pay for

    No API key needed. It uses the Codex CLI, a program from OpenAI that you install, and you sign in from inside the app. Your plan's usage limit applies.

  • An API key billed per use

    An API key is a password an AI service gives you so programs can use your account. A Claude key works, and so does one from a service compatible with the OpenAI API. The service is the one that bills you. The app estimates the cost before the run and shows what was billed after.

With the online options, the app asks for your permission first and shows which text will be sent. Only the extracted lines go out, never the game file.

What makes it easier if you are not technical

  • No programming

    You do not write code or open a byte editor, the kind of program that shows a file number by number. The work is done with buttons. Some games still need manual adjustments: see the limits.

  • The game stays on your computer

    The game file stays on your machine. With an online AI, only the lines go out, and only with your permission.

  • The original is never changed

    The app works on a copy. The file you dropped in stays exactly the same.

  • A translation that does not fit goes back on its own

    Each line has limited room inside the game. If the translation is too long, the app asks the AI for a shorter one, without you doing anything.

  • What is not text stays out of the queue

    The game's internal names and pieces of the file that only look like text are not sent to the AI.

  • You can cancel

    You can stop the translation at any time. What has already been translated stays saved.

  • You end up with a patch

    A small file with just the translation. Anyone who has the original game applies the patch and gets the same result. You share it without distributing the game.

  • Free and open source

    MIT license. Anyone can read the code and see what the app does.

What it cannot do yet

  • Compressed text. Some games store their text compressed. On Game Boy Advance the app now reads and rewrites the most common format, but no real game has been through it yet. On other consoles it only counts those blocks.
  • Japanese games. The app reads the Japanese of disc games (Shift-JIS) and the 16-bit kind used by the first real Japanese game tested, for Game Boy Advance. In that game the script lines can grow and the app breaks the lines to fit the text box: half of them have been translated, and the first scene was seen running in an emulator. There are no accents, because the game's font has none, and menus, items and names still only fit at the length of the original.
  • Fonts and drawn text. It does not edit the game's letters or text that is an image, such as title screens and some menus.
  • Size. Most of the text can only be as long as the original.
  • Cartridge games. Choosing the text region and the game's letter table is still manual work.

When the system complains

macOS says the app is damaged. That is its warning for an unsigned app.

  1. Open the downloaded file and drag the app to the Applications folder.
  2. Open the Terminal app, paste this line and press Enter: xattr -cr "/Applications/RomTranslate Studio.app"
  3. Open RomTranslate Studio.

Questions from people just arriving

What is this “game file” and where does it come from?

It is the digital copy of what is on a cartridge or a disc, stored as a file. Many people call it a ROM or an ISO. It comes from the copy of the game that you have. This site and the app do not offer games, do not download games and do not point to where to download them.

Is this allowed?

We are not lawyers, and this is not legal advice. What we can state is what the app does: it does not distribute games, it works only with the file you already have, and what gets shared is the patch, which holds the translation and not the game. The app's license covers only the app itself: it grants no rights over any game, trademark or translation of third-party work.

Do I need to know how to program?

No. The whole path is done with buttons in the app's window. For some cartridge games you still have to point out by hand where the text is and which letter table the game uses. That is not programming, but it takes work, and it is on the list of what the app cannot do on its own yet.

Does it work with any game?

No. All support is experimental. Each game stores its text in its own way, and there are cases the app cannot read yet: most compressed text, some Japanese games and text drawn as an image. So far, only one real game has been through the whole process.

Does the game leave my computer?

The game file, never. With the AI that runs on your computer, nothing leaves. With an online AI, only the extracted lines are sent, and the app asks for your permission first, showing which text will go out.

How much does it cost?

The app is free. The AI can be free (the one that runs on your computer), it can be the ChatGPT subscription you already pay for, or it can be an API key, billed per use by the service you choose.

How long does it take?

It depends on the AI. With a ChatGPT subscription, the measured pace was about 5 lines per second. At that pace, a game with about 9 thousand lines takes around half an hour.
