    How to apply a translation

    You need your own copy of the game, the same one the translation names. This site has no games.

    1. Check your file

      Your game's SHA-256 must match the translation's. The app shows this number when you drag the game into the window. In the Terminal: shasum -a 256 game.gba on Mac and Linux, or certutil -hashfile game.gba SHA256 on Windows.

    2. Download the patch

      It is the translation's .bps file. It holds only what changes in the game, so it is small.

    3. Apply it to a copy

      Open a patcher such as Rom Patcher JS, which runs in the browser and does not upload the game anywhere. Choose the game and the patch and save the result. If the file is not the translation's, the BPS patch refuses it. Keep the original.

    Send your translation

    Translated a game with RomTranslate Studio? Send it to the catalog, and the next person does not have to start from scratch.

    Sending is a pull request on GitHub, which you can do in the browser. An automatic check looks at the folder, and the maintainer reviews it before accepting.

    What goes in

    • The patch, as BPS: choose BPS on the app's patch screen.
    • The manifest.json the app exports with it, plus the game's name, yours, the version, what you checked and what you did not.
    • The game profile (perfil.toml) and the letter table, if the game needed them: whoever comes next can improve the translation without studying the game again.

    What never goes in

    • The game (ROM or ISO), BIOS files or archives.
    • The translations.csv, because it carries the game's original text.
    • Screenshots and links to download games.

    The check refuses any file outside the list and a patch that carries the game along.

    Rules and legal notice

    Why are game names shown here?

    So you can find yours. The name only says which game each patch applies to. Names and trademarks belong to their owners, and the catalog is not affiliated with them.

    Is this allowed?

    We are not lawyers, and this is not legal advice. The catalog has no games and no links to download them: everyone uses the copy of the game they own, and the patch holds the translation, not the game.

    Who owns each translation?

    Whoever made it. By sending one, you state that you made the translation, or have permission from who did, and agree to its redistribution here.

    Is the translation finished?

    Each one says what was checked and what was not. The app is in testing, and a translation may have cut text or untranslated parts. Found a problem? Tell the translator or send a new version.

    I want a translation removed from the catalog

    If you hold rights to the game or are the translation's author, open an issue on the catalog repository naming it. It will be removed.
